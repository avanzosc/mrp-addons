========================
MRP Operation BOM Status
========================

This module adds the BoM status to Manufacturing Operations.

It extends ``mrp.routing.workcenter`` to include a stored related field
that reflects whether the related Bill of Materials is active or archived.

It also adds:

* Filters for BoM Active and BoM Archived
* Group by BoM Status
* BoM Status field in tree and form views
