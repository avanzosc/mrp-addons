============================
Repair Calendar View Filters
============================

Overview
========

The **Repair Calendar View Filters** module adds a filter to the repair calendar view to filter repair orders by employee.

Features
========

- **Employee Filter**:
  
  - Adds a filter for the `employee_id` field in the repair calendar view to allow filtering by employee.

Usage
=====

1. **Install the Module**:
  
   - Install the **Repair Calendar View Filters** module from the Apps menu.

2. **Open Repair Calendar**:
  
   - Navigate to *Repairs* → *Repair Orders* → *Repair Calendar*.
  
   - Use the newly added employee filter to filter repair orders by employee.
