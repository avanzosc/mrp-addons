#. Go to *Manufacturing > Manufacturing Orders* and open or create a manufacturing order.
#. In the components list, you can optionally show the columns *Estimated Cost* and *Real Cost* for each raw material move.
#. In the work orders tab, you can optionally show *Estimated Cost* and *Real Cost* for each operation.
#. The manufacturing order header displays the aggregated cost fields: Estimated/Real Material Cost, Estimated/Real Work Cost, Estimated/Real Manufacturing Cost, and Cost Unit Price.
#. When the manufacturing order is completed, the real cost is automatically propagated to the finished product moves and to the production lot (if any).
