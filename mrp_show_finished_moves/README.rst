=======================
MRP Show Finished Moves
=======================

This module extends the Manufacturing (MRP) functionality to improve the visibility and editability of finished stock moves and move lines within Manufacturing Orders (MOs) and Work Orders (WOs).

**Features**

- Adds a **"Finished Moves"** tab in the Manufacturing Order and Work Order forms to display the finished move lines.
- Introduces a **stat button** on the MO form to quickly access all related finished move lines via a dedicated tree view.
- Automatically assigns the production lot to move lines when created, if available.
- Enhances the stock move tree view with editable lines, optional fields, and a new **"Show Details"** button.
- Adds a dedicated menu item under Manufacturing to directly view all finished move lines.
