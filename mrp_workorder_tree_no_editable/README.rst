==============================
MRP Workorder Tree No Editable
==============================

This module extends the manufacturing work order (mrp.workorder) model in Odoo by adding a new non-editable tree view of work orders accessible via a dedicated submenu under Manufacturing. 
The tree view displays key fields but disables creation and editing to prevent modifications from the list. 
Additionally, it provides an action to open the work order form view from the tree, ensuring seamless navigation.

* Non-editable tree view for mrp.workorder with relevant fields.

* Menu item **Work Orders - No Editable** under Manufacturing to access this view.

* Form view opens on record click or via the custom action method.
