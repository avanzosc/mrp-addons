===============================
MRP Workcenter Productivity OT Report
===============================

This module adds an analysis (tree + pivot) entry point to ``mrp.workcenter.productivity``
to explore Work Order time tracking in Community Edition.

It also adds helper fields:
- Manufacturing Order (production_id)
- Product (product_id)
- Procurement Group (procurement_group_id)
- Time (hours) (duration_hours)
- Plates fabricated (plates_done)
- Average speed (speed) aggregated by AVG in pivots
