=======================
Workcenter Productivity
=======================

Workcenter Productivity > Tracks the productivity in workcenters within the manufacturing process. It calculates and displays average speed, time spent, and items produced, with pivot views for detailed analysis.

Features
========

* Adds detailed tracking of workcenter productivity, including time spent, items produced, and average speed.
* Allows filtering and grouping by work order, production order, product, procurement group, work center, and more.
* Provides pivot views for data analysis and dashboard integration.
